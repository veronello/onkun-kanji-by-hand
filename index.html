About the project

Kanji ON is a project designed to help learners review Japanese kanji included in the official Jōyō Kanji List (常用漢字表, 2010 revision).

The project is intended for learners who have already studied the required set of kanji and wish to refresh their knowledge and bring it back into active use.

The review process consists of exercises based on on-reading compounds and kun-readings, requiring learners to write the corresponding kanji by hand.

An additional knowledge assessment test is currently under development.
