# Онные упражнения: карточки 1–300 и скрытие по ID

Исходное состояние: `a0c4593` в `feature/excel-12-card-preview`, `a0c3599` в `main`. В обеих ветках ON содержал 537 заданий из карточек 1–204, не применяя уже сохранённые пометки видимости.

## Итоговый набор

- В диапазоне 1–300 — 1299 исходных записей, 1297 из них имеют подготовленные переводы RU/EN. Две строки без переводов (EX-00998, EX-01019) относятся к KUN; неподготовленные данные не добавляются.
- ON: 790 исходных кандидатов, 770 одобренных ID, 20 решений об исключении. Все прежние 537 одобренных ID сохранены.
- Добавлено 233 задания: 96 из карточек 205–252 и 137 из 253–300. Все 245 новых ON-кандидатов рассмотрены целиком, с учётом группы чтения целевого знака, чтений других компонентов, значения и словарных записей.
- Видимо 769 заданий: EX-00164 — 一座 / ichiza скрыт по `YES`. Прирост относительно прежних 537 видимых заданий составляет 232.
- Фактический диапазон видимого набора — 1–300. Число заданий, подпись диапазона, счётчик, прогресс и завершение вычисляются после фильтрации видимости.
- Все 19 скрытых KUN ID сохранены. KUN остаётся 470 одобренных / 451 видимое задание.

Источник: `OnKun_Translations_1-300_2026-10-23 upd hide readings.xlsx`. SHA-256: `0bb4620b96fd898b4c1e5ccebe729f3f12689cadb95aa7562909d3dacda59972`.

`OnKun Examples` содержит исходные тексты. Лист `OnKun Examples hide readings ` (с пробелом в конце имени) содержит дополнительный столбец `Hide from website`. Существующий `scripts/import_drill_visibility.py --check` сопоставляет обе копии по заголовкам и ID, проверяя остальные поля независимо от смещения столбцов. `data/drill-visibility.json` уже точно совпадал с вложением, поэтому он и импортёр не изменены.

## Данные и поведение

`data/on-drill-selection.json` хранит только одобренные ID и решения об исключении. Полные написания, ромадзи и RU/EN загружаются из общих данных карточек; отдельной копии текстов упражнений нет. Исходные Excel, данные и интерфейс карточек, KUN, общие скрипты, стили и README не изменяются.

ON загружает существующий общий файл видимости тем же способом, что KUN. Скрывается конкретный ID, без удаления из справочных карточек и без распространения на другой пример или чтение. EX-00163 — 一度 и EX-00165 — 第一 остаются видимыми. Снятие флага возвращает 一座 на прежнее место в исходном порядке, с прежними текстами.

Тип ON/KUN в Excel относится к целевому знаку и сам по себе не классифицирует всё слово. Наличие окуриганы также не является фильтром: 概して / gaishite и 関する / kansuru сохранены как полные словарные формы. Менее привычные, но онные 格子 / kōshi, 堪能 / kannō и 眼力 / ganriki сохранены по данным источника. Ромадзи и переводы не нормализуются и не заменяются другими вариантами.

Повторы проверены по паре написание + чтение с дополнительным сравнением значения. Разные чтения одного написания не объединяются. При совпадении значения оставлена первая исходная запись, без объединения переводов. Простота слова не служит основанием для исключения.

Сохраняется взаимодействие: ромадзи и перевод выбранного языка, запись на бумаге, раскрытие полного японского ответа, следующее/предыдущее слово. Служебные и переводческие заметки не выводятся.

## Проверки и публикация

Пройдены:

- `scripts/test_on_source.py`: 1299 точных сопоставлений с Excel по ID, карточке, целевому знаку, полному написанию, ромадзи, RU/EN, типу и группе чтения. Все 790 ON распределены между 770 одобренными и 20 исключёнными. Проверены 769 видимых заданий, единственный скрытый ON ID, сохранение 19 KUN-флагов и неизменность SHA-256 Excel.
- `scripts/import_drill_visibility.py --check`: заголовки и ID на листе со смещёнными столбцами, все скопированные поля, 20 флагов `YES` и совпадение существующего JSON с вложением.
- `scripts/test_on_drill.cjs`: все 769 видимых заданий полностью пройдены в обоих языках на 1440×1000, 390×844 и 320×740 (4614 сочетаний задание/язык/экран). Проверены порядок и ID, полные ответы, точность ромадзи и переводов, скрытие ответа до нажатия, навигация назад, счётчик, прогресс, завершение, повтор и отсутствие служебных заметок и горизонтального переполнения.
- Проверены переключение языка при раскрытом ответе и во время загрузки, тёмная тема, восстановление после HTTP 503, неверного ID/типа/перевода, повтора задания, одиночного иероглифа, отсутствующего/некорректного файла видимости, повторного скрытого ID и скрытия всех заданий. Снятие только флага EX-00164 возвращает 一座 с исходными текстами и количеством 770. Скрытие всех заданий крайних карточек меняет подпись на 2–299 и пересчитывает количество.
- 一座 / ichiza отдельно проверено в справочной карточке № 41 в RU/EN: запись остаётся видимой, несмотря на скрытие из ON.
- `scripts/test_kun_drill.cjs`: все 451 видимое KUN-задание в RU/EN на тех же трёх размерах (2706 сочетаний), включая ошибки загрузки, восстановление и возврат скрытых заданий. `scripts/test_kun_source.py`: 470 одобренных / 451 видимое / 19 скрытых, без изменений текстов и флагов.
- `scripts/test_cards.cjs`: существующие проверки Grid/Single, двух языков, раскрытия, поиска, навигации, отложенных чтений и ошибок на 1440, 390 и 320 пикселях.
- `scripts/test_import.py`: 7 существующих тестов; проверка синтаксиса JavaScript и `git diff --check`.

Снимки вопросов, ответов и тёмной темы просмотрены. Для тестовой среды установлен Noto Serif JP; код и шрифты сайта не меняются. Браузер — Google Chrome for Testing 156.0.8078.47; мобильные размеры проверены с эмуляцией touch. Физические телефоны и Safari не проверялись.

В main переносятся только шесть файлов этого изменения: ON-скрипт, список ID, два ON-теста, этот отчёт и обновлённая версия ON-скрипта в `on.html`. Сам `on.html` берётся из актуальной main, чтобы сохранить отдельные правки ссылок и общего скрипта. README, KUN, общий файл видимости, данные и интерфейс карточек, стили, источники и остальные изменения main сохраняются.

Для повторной проверки при работающем HTTP-сервере:

```sh
python scripts/test_on_source.py /path/to/source.xlsx
python scripts/import_drill_visibility.py /path/to/source.xlsx --check
python scripts/test_kun_source.py /path/to/source.xlsx
node scripts/test_on_drill.cjs
node scripts/test_kun_drill.cjs
node scripts/test_cards.cjs
python scripts/test_import.py
```

Для браузерных тестов нужны Playwright и Chromium, без новых зависимостей сайта. Адрес сервера — `CARDS_BASE_URL` (по умолчанию `http://127.0.0.1:8765`), путь к браузеру — `CHROMIUM_EXECUTABLE_PATH`. Необязательные снимки — `ON_SCREENSHOT_DIR`.
