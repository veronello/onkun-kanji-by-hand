## Интерфейс и скорость

Карточки сохраняют исходную компоновку, цвета и темы. Японские ON/KUN берутся из официальной таблицы; романизация примеров — только из H. У каждого примера сохранены ID, группа 音訓, тип ON/KUN, статус и номер строки. Доступна вся база 2 136 иероглифов; поиск по одному иероглифу/номеру. Тестовый переключатель на первые 12 и видимый счётчик диапазона убраны.

One card показывает одну карточку со всеми примерами; Grid — 12 карточек на странице, не более трёх примеров каждой до раскрытия. Для остальных есть локализованная кнопка с количеством скрытых записей и обратным сворачиванием; `Open` переходит к полной карточке. JSON поделён на 45 частей по максимум 48 карточек. Начальная загрузка — только manifest и первая часть. Кэш ограничен четырьмя частями. Полные Source/Review/Audit не загружаются интерфейсом. При ошибке есть повторная загрузка; подмена старой демонстрационной базой не выполняется.

Переводы показаны под ромадзи и переключаются вместе с RU/EN. Для остальных примеров видна помета о незаполненном переводе. Значения, зависящие от контекста, отмечены краткими примечаниями; у 20 записей второй партии, 40 записей третьей и 46 записей четвёртой есть явный флаг ручного выбора смысла. [Первая партия и источники](translations-12.md); [вторая партия и источники](translations-13-24.md); [третья партия и источники](translations-25-48.md); [ручная проверка № 25–48](translations-25-48-review.md); [четвёртая партия](translations-49-72.md); [ручная проверка № 49–72](translations-49-72-review.md).

| Пример | Romaji | RU | EN |
| --- | --- | --- | --- |
| 哀れな話 | aware na hanashi | печальная история | a sad story |
| 宛先 | atesaki | адрес получателя; адресат | recipient’s address; addressee |

Существующие отдельные ON/KUN упражнения остаются на своих наборах. Полная база подключена к разделу карточек; новые упражнения по всей базе в эту задачу не входят.

## Обновление Excel

Заменить исходник новой проверенной версией под тем же именем (или передать `--source`), затем выполнить:

```sh
python3 -m pip install -r scripts/requirements.txt
python3 scripts/import_excel.py
python3 scripts/test_import.py
```

Импорт не записывает ничего в Excel и не генерирует чтения. Неизвестные статусы закрыты по умолчанию. Количество записей и иероглифов контролируется. Если новая база имеет другое число записей, сначала разобраться с изменением состава, затем обновить ожидаемые контрольные значения. Переводы хранятся отдельно и сверяются по ID, японскому слову и H: несовпадение останавливает импорт. Выполнить тесты, просмотреть изменённые карточки и сохранять обновление только в этой ветке.

Запуск версии:

```sh
python3 -m http.server 8765
```

Открыть `http://localhost:8765/cards.html` (полная база). Старый URL `?excel-preview` теперь также открывает всю базу. Открытие через `file://` не поддерживается: данные загружаются по HTTP.

- `node --check cards.js` и `git diff --check` пройдены.
- Chromium: 1440×1000, 390×844 и 320×740. Проверены One card/Grid, RU/EN, поиск, открытие карточки из сетки, первая/последняя страницы, отсутствие тестового переключателя, пустая карточка 朕, шаблон, предварительное чтение, ручной статус, быстрые переключения, ошибка сети и повторная загрузка, старый URL `?excel-preview`. Все проверки пройдены; необработанных ошибок JavaScript и горизонтального переполнения нет.
- Начальная загрузка базы делает 2 запроса JSON. Архивные Source/Review/Audit при открытии карточек не запрашиваются.
- Светлая и тёмная темы просмотрены при ширине 1440, 390 и 320 пикселей. В тестовом окружении внешний Google Fonts недоступен; для визуальной проверки подставлен тот же Noto Serif JP локально. Японские символы и переносы проверены с этим шрифтом. На сайте сохраняется существующая ссылка Google Fonts и системные запасные шрифты.
- Мобильные размеры проверены в браузере; физический iPhone/Android и Safari в этом окружении не проверялись.

Проверка 101 записи № 25–48: `node scripts/test_translations.cjs`. Проверка всех 107 записей № 49–72 в обоих языках и режимах: `CARDS_TRANSLATION_START=49 node scripts/test_translations.cjs`.

Повторяемая UI-проверка: установить Playwright/Chromium, запустить HTTP-сервер и выполнить `node scripts/test_cards.cjs`. При необходимости указать `CARDS_BASE_URL` и `CHROMIUM_EXECUTABLE_PATH`.

## Упрощение интерфейса

Убран тестовый фильтр «Первые 12» и видимый счётчик диапазона над карточками. По умолчанию доступны все 2 136 иероглифов, навигация «Назад / Дальше» и поиск сохранены. Для доступности текущий диапазон остаётся в скрытом `aria-live`-статусе. Изменения выполнены только в экспериментальной ветке.
