# Кунные упражнения: диапазон 1–204

Ветка: `feature/excel-12-card-preview`. Исходная точка: `c747c50`.

## Набор

- В приложенной таблице: 913 переведённых примеров, из них 545 ON и 368 KUN.
- Подключено: **341 уникальное задание** на основе 341 ID.
- Не включено 27 записей KUN: 24 смешанные, 1 открытый шаблон, 1 контекстно неоднозначная, 1 повтор.
- У вошедших заданий фактический диапазон карточек **2–204**: у № 1 только ON. Подпись рассчитывается по загруженному набору.
- Поле ON/KUN в источнике относится к целевому иероглифу. Для включения вручную рассмотрены остальные компоненты слова; одна эта пометка не служит автоматическим фильтром.

Проверены все 368 кандидатов, в том числе составные слова, рэндаку, счётные формы и географические названия. Разные чтения одинакового написания сохранены: 栄える (sakaeru / haeru), 汚す (kegasu / yogosu), 汚れる (kegareru / yogoreru), 汚れ (kegare / yogore), 音 (oto / ne), 下 (shita / shimo / moto), 開く (hiraku / aku), 開ける (hirakeru / akeru), 外 (soto / hoka).

## Источник и общие данные

Исходник: `OnKun_Translations_1-204_2026-10-17.xlsx`, лист `OnKun Examples`, диапазон № 1–204. SHA-256: `18b8be25a7ad8a223972fcad929b420ff598b251eb6af16149213a706ae8a2c7`.

Все 913 пар японское написание/ромадзи и 1826 переводов RU/EN точно совпадают с уже имеющимися `data/excel/cards/000.json`–`004.json`; сопоставление выполнено по ID, а не позиции строки. Исходный Excel и данные карточек не изменены.

`data/kun-drill-selection.json` хранит одобренные ID и решения об исключении. Упражнения получают написание, ромадзи и оба перевода непосредственно из общих данных карточек. Отдельной копии текстов заданий нет. Порядок соответствует источнику. Новые ID не попадают в упражнения без явного добавления в проверенный список. Загрузка завершается ошибкой при потерянном ID, неподходящем типе, отсутствии перевода/ромадзи, повторе ID или пары написание + чтение.

Служебные и переводческие заметки в упражнения не выводятся. Японский ответ, включая окуригану, частицы, だ и приставки, показывается полностью, без пересборки из целевого иероглифа.
