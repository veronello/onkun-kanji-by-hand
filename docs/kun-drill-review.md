## Источник и общие данные

Исходник найден по точному имени в ChatGPT Library: `OnKun_Translations_1-300_2026-10-23.xlsx`, версия 10, лист `OnKun Examples`, диапазон № 1–300. SHA-256: `803a45fb0b4df20322d5cd8402dc2965fd76be4e3e44f84550444943dfbf660b`.

Все 1299 записей по японскому написанию/ромадзи и 2594 подготовленных перевода RU/EN точно совпадают с уже имеющимися `data/excel/cards/000.json`–`006.json` и переводами из `data/translations-12.json`; сопоставление выполнено по ID, а не позиции строки. Два пустых шаблона также сверены. Исходный Excel и общие данные карточек не изменены.

`data/kun-drill-selection.json` хранит одобренные ID и решения об исключении. Упражнения получают написание, ромадзи и оба перевода непосредственно из общих данных карточек. Отдельной копии текстов заданий нет. Порядок соответствует источнику. Новые ID не попадают в упражнения без явного добавления в проверенный список. Загрузка завершается ошибкой при потерянном ID, неподходящем типе, отсутствии перевода/ромадзи, повторе ID или пары написание + чтение.

Служебные и переводческие заметки в упражнения не выводятся. Японский ответ, включая окуригану, частицы, だ и приставки, показывается полностью, без пересборки из целевого иероглифа.
