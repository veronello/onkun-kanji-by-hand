# Онные упражнения: диапазон 1–204

Ветка: `feature/excel-12-card-preview`. Исходная точка: `d4f2f5c` (341 кунное задание уже включено).

## Набор и отбор

- В источнике 913 записей: 545 ON, 368 KUN.
- Включено **537 уникальных заданий** по ID, в порядке источника. Фактический диапазон карточек **1–204**.
- Не включено 8 ON: 3 смешанных, 2 пограничных для отдельного решения и 3 повтора.
- Прежний демонстрационный набор: 44 задания. Сохранено по исходным ID 23, добавлено 514; 21 прежнее задание не перенесено. Изменение общего количества: +493.
- Пометка ON/KUN в Excel относится к целевому иероглифу. Все 545 ON-кандидатов просмотрены целиком с учётом группы чтения, других компонентов и словарного разбора; длина написания и отсутствие окуриганы не служат классификацией.
- Простота задания не является основанием для исключения. Включены и обычные слова (映画, 安全, 意味), и полные словарные глаголы на する (逸する, 益する, 謁する, 嫁する, 課する, 賀する, 介する).
- Изолированные онные чтения не создаются из списка чтений карточки. Единственный одноиероглифный кандидат 課 / ka консервативно вынесен на отдельное решение; это не утверждение, что у него нет самостоятельного словарного значения.
- Разные чтения одинакового написания не объединяются. Повторы определяются парой написание + ромадзи, а при отличающихся переводах требуется проверка значения: у трёх повторов выше значения совпадают. Сохраняется текст первого ID, переводы не пересобираются.

## Источник и архитектура

Источник: `OnKun_Translations_1-204_2026-10-17(2).xlsx`, лист `OnKun Examples`. SHA-256: `18b8be25a7ad8a223972fcad929b420ff598b251eb6af16149213a706ae8a2c7`.

Все 913 записей сверены по ID с общими JSON карточек: совпадают японское написание, ромадзи, RU/EN, номер карточки, целевой иероглиф, тип и группа чтения. Исходный Excel и данные карточек не изменены.

`data/on-drill-selection.json` содержит только одобренные ID и решения об исключении. Написания, ромадзи и переводы загружаются из `data/excel/cards/000.json`–`004.json`. Будущие исправления текстов выполняются в общих данных, отдельной копии текстов упражнений нет. Список включения явный: новые строки автоматически не попадают в упражнения.

Загрузка, ошибки и повтор загрузки работают по существующему образцу KUN. При неверном ID, типе, неподготовленной записи, пустом тексте, повторе ID/задания или одиночном иероглифе загрузка завершается ошибкой. До готовности кнопка ответа недоступна. Подпись диапазона, счётчик, прогресс и итоговое число вычисляются по загруженным заданиям. Служебные заметки не выводятся; ответ показывается полностью.
