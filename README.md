# 音くん — Kanji by Hand

**On readings. Kun readings. Kanji by hand.**

音くん is a bilingual Russian–English practice site for recalling and writing kanji by hand. The first exercise sets are based on study drills compiled by the author while studying Japanese in 2013.

The learning loop is intentionally simple:

1. Read the prompt.
2. Write the answer on paper.
3. Reveal the correct kanji.
4. Mark it as remembered or save it for another round.

The first prototype includes an on-reading practice set. Kun readings, mixed practice, and final tests will follow.

## Run locally

Open `index.html` in a browser. No build step or server is required.
