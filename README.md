# 音くん — Kanji by Hand

音くん (OnKun) is a Russian–English website in development for reviewing kanji and writing them by hand on paper.

The exercises draw on the author's own study materials, compiled during her university years starting in 2013, with new original exercises planned.

## Current state

The site contains the project description and four practice-mode placeholders. Sample exercises have been removed while the content is being prepared; practice sessions are not available yet.

The interface includes a Russian–English language switcher, a charcoal-grey palette with smoky-blue accents, an 音くん wordmark, and an ON icon for browser tabs and the home screen.

## Planned practice modes

- **On readings:** kanji review through compounds with on readings.
- **Kun readings:** kanji review through words with kun readings.
- **Mixed practice:** kanji review with a mix of on and kun readings.
- **Final test:** a full-block recall test with answers shown at the end.

The planned practice flow is reading a prompt, writing the answer on paper, comparing it with the correct kanji, and marking words for further review.

## Run locally

Open `index.html` in a browser. The site uses HTML, CSS, and JavaScript, with no build step or server required.
