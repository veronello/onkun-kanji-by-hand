# KANJI ON — Kanji by Hand

**[Open the website / Открыть сайт](https://veronello.github.io/onkun-kanji-by-hand/)**

KANJI ON is a Russian–English website in development for reviewing kanji and writing them by hand on paper.

The exercises draw on the author's own study materials, compiled during her university years starting in 2013, alongside new original exercises.

## Current state

The site contains the project description, four practice-mode placeholders (ON, KUN, ON-KUN, and OFF), and a Miscellaneous / Разное section for sources, articles, interesting materials, and photos. Practice sessions and the Miscellaneous collection are not available yet.

The interface includes a Russian–English language switcher, a soft-white default theme with graphite text and muted green accents, and an optional dark theme. The theme choice is saved in the browser. The KANJI ON wordmark and green ON icon appear on the site and in browser or home-screen shortcuts.

## Planned practice modes

- **On readings:** kanji review through compounds with on readings.
- **Kun readings:** kanji review through words with kun readings.
- **Mixed practice:** kanji review with a mix of on and kun readings.
- **Final test:** a full-block recall test with answers shown at the end.

The planned practice flow is reading a prompt, writing the answer on paper, comparing it with the correct kanji, and marking words for further review.

## Run locally

Open `index.html` in a browser. The site uses HTML, CSS, and JavaScript, with no build step or server required.
